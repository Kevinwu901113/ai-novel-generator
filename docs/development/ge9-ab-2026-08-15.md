# GE-9 首轮 A/B：反 AI 味 prompt 规则的人工盲评结果

> 状态：**初步结果，尚不构成 §17 要求的完整证据**（评分独立性不足，见 §5）。
> 日期：2026-08-15。原始数据在仓库外：`~/Documents/novel-ge9-experiment/`。

## 1. 一句话结论

**antislop-v2 把确定性 AI 味指标改善了约 20 倍，但人读起来没有任何可感知的改善，方向甚至略微为负。**
这说明那份 22 条的 AI 味词表**不是人类感知 AI 味的有效代理**；照它优化能把指标做得很漂亮，
读者却感觉不到。若把它当质量门的验收标准，是在优化一个假目标。

## 2. 实验设置

- 套件 `gq2-genre-coverage-v1`：8 case，覆盖 4 视角 / 3 时态 / 8 类题材，篇幅 850–1500 字。
- 两臂：`baseline-one-shot-v1` 与 `antislop-v2`（= baseline prompt + `ai-writing-quality.md` §4
  的显式反 AI 味文风规则 + 检测器驱动的定点改写第二趟）。
- 每臂每 case 2 个候选（seed 1/2），共 32 个候选，4 次 run 全成功、零失败。
- 模型 `mimo-v2.5-pro`，temperature 0.7，maxTokens 8192。
- 盲评：4 份 output suite 经 `mergeOutputSuites` 合并为每 case 4 候选，`generateBlindPacket`
  跨臂混排，alias 不携带策略信息。

## 3. 确定性指标（自动，无人参与）

|             | 候选数 | 平均字数 | 有 AI 味命中的候选 | 命中总次数 | 每千字命中 |
| ----------- | ------ | -------- | ------------------ | ---------- | ---------- |
| baseline    | 16     | 1167     | 10/16              | 24         | 1.29       |
| antislop-v2 | 16     | 999      | 1/16               | 1          | 0.06       |

归一化后仍有约 20 倍差距，长度差异（antislop 短 14%）不足以解释。

**但该指标对 antislop-v2 存在结构性循环**：v2 的 prompt 明确禁止的，正是该词表检测的对象。
它测的是"模型是否服从指令"，不是"文字是否更好"。

## 4. 人工盲评（三个维度，1–5 分）

| 维度                         | baseline | antislop-v2 | 差（v2 − base） |
| ---------------------------- | -------- | ----------- | --------------- |
| continueReading 想继续读     | **3.25** | 3.00        | −0.25           |
| languageNaturalness 语言自然 | **2.94** | 2.81        | −0.13           |
| aiSmellAbsence 没有 AI 腔    | **2.44** | 2.31        | −0.13           |
| 平均名次（越低越好）         | **2.31** | 2.69        | —               |
| 拿第 1 的次数                | 4/8      | 4/8         | —               |

逐 case 配对差非系统性：antislop 在 `letters-unsent` / `restrained-reunion` / `folk-night-rite`
占优，在 `suspense-corridor` / `two-voice-dialogue` / `duel-on-ice` 落后，`palace-farewell` 打平。
赢输相互抵消，拿第一的次数是 4:4 死平。

其余五个维度（expectationFit / characterCredibility / plotProgression / concision / continuity）
**未评**，按未评记录，不参与任何均值。

## 5. 这份结果不能支撑什么（重要）

- **没有评分者间一致性。** 两位评分者是**一起**评的，第二位表示同意第一位的判断，不是独立评分。
  在非独立数据上算 Krippendorff alpha 会因构造而虚高，故不计算、不报告。本文件的分数按
  **"两人共识评分"**记录，不冒充两名独立评分者。
- **差异量级在噪声内。** 0.13–0.25 分、每臂 16 个观测。**不得据此宣称 baseline 更好**；
  可支持的表述只有"antislop-v2 未表现出人类可感知的改善"。
- 单一模型（MiMo v2.5 Pro）、单一温度、850–1500 字短篇；产品实际章节 3000–15000 字，
  结论不能外推到长章节。

## 6. 已可采取的行动

1. **不要把确定性 AI 味指标当作质量验收标准。** 它可作为退化告警，不可作为改善证据。
   `ai-writing-quality.md` §4 已写明"这些指标用于发现明确退化模式，不是 AI 文本检测器"，
   本轮实验为该判断提供了第一份实证支持。
2. **antislop-v2 的那套 prompt 规则暂无留用理由**，但也无证据表明有害。保留 `antislop-v1`
   作为"只有检测器、无 prompt 规则"的消融臂。
3. 若要得到 §17 要求的完整证据，需要**一位此前未参与、未看过本轮文本的评分者独立评一遍**
   同一份盲评包。届时 alpha 才有意义。
