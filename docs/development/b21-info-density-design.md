# B21 设计：信息密度——任务中心产品化、蓝图直达成稿、项目卡时间

> 背景：D13 评审遗留的信息密度问题（任务中心开发者仪表盘气质、项目卡无信息量、
> 蓝图就绪后无动作入口）。D13 收口批。

## 1. 决策

### D-B21-1 任务中心产品化

- **任务行以任务名为主**：首行「章节自查 + 状态徽章」（原首行是 mono 哈希短 ID
  ——写作者不消费哈希）；次行「开始时间 · 耗时 · 尝试 N（仅 N>1 时显示）」。
  哈希 ID 保留在点开的任务详情里（排障场景仍可达）。可访问名称同步改任务名优先。
- **统计瘦身**：八块工程指标平铺改为一行产品摘要「N 次调用 · 成功 X · 失败 Y」，
  Token/延迟四项收进「用量与延迟」折叠（`<details>`）——它们是排障/成本信息，
  不该占首屏权重。加载失败/过期语义（保留上次数据 + 过期提示）原样保留。
- 列表 listbox/roving tabindex 键盘导航机制不动。

### D-B21-2 蓝图就绪面板接「去成稿」

B18 文案更正时留的口子（「跳转按钮涉及 App 导航接线」）本批兑现：
ProjectReadyPanel 增加可选 `onGoToManuscript`，App 传
`handleSelectJourneyStage('manuscript')` 经 BlueprintRegion 透传——项目就绪后
不必再手动去点旅程导航。按 D-B8-7 纪律，回调缺省时不渲染按钮（不出现无后端的
空承诺按钮）。逐章直达（点章节结构某章直接开生成）需要跨 Region 状态提升，
本批不做，随后续需要再议。

### D-B21-3 项目卡相对时间

「最近打开 · 2026/8/17 15:58:07」的秒级精度是噪音。新增 `formatRelativeTime`
（分钟内=刚刚，60 分钟内=N 分钟前，24 小时内=N 小时前，30 天内=N 天前，更早回落
到日期），项目卡与任务行共用。完整时间戳仍在 `title` 悬停可查，信息不丢。

### 登记（非本批实现）：故事知识图谱

负责人 2026-08-18 定向：参照 GraphRAG/LightRAG 为长篇一致性建故事图结构（实体/
关系/事件时间线/伏笔线程，逐章抽取、检索式上下文、一致性核验）。已登记进
`graph-engineering-roadmap.md` GE-9 段（含设计要点清单），届时单独出设计文档。

### 明确不做：项目卡真实阶段/进度

阶段真相在各项目自己的 project.sqlite（Graph runs），app.sqlite 只是索引；列表页
拿全量阶段要么打开每个项目库（列表变 O(n) 重操作），要么做反规范化阶段缓存
（写回协议 + 失效语义，独立后端设计）。伪造或猜测阶段违反本项目「文案不说谎」
纪律，故整体推迟到有真实数据源的后端批次。
