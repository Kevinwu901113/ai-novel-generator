# B19 设计：设置页——从右侧抽屉改独立页面

> 背景：D13 评审后负责人 2026-08-17 追加拍板：下一批做设置页，明确否定现行右侧
> 抽屉（Sheet）形态，页面编排交实现方设计。原 D13 排期中的「读写分离」「信息密度」
> 顺延（B20/B21）；评审中记录的设置抽屉两处编排问题（添加表单排在已配置服务前、
> 破坏性按钮占按钮行首位）随本批一并解决——正在重建这个面，没有理由把已知问题
> 原样搬进新页面。

## 1. 决策

### D-B19-1 设置是页面，不是抽屉

- App 新增 `settingsOpen` 状态：为 true 时 main 区域挂 SettingsPage（header 保留，
  中央标题切换为「设置」；创作旅程/首页状态不销毁，返回即恢复原视图）。
- 入口不变：rail/底部导航「设置」、header 模型芯片、首页服务状态卡。rail 与底部
  导航的「设置」在页面打开时呈 active（`aria-current="page"`）。
- 任务活动保持抽屉——它是工作台的伴随信息，随叫随走；设置是一组独立任务，
  值得整页空间。`shell-state` 的 DrawerId 收窄为 `'tasks'`。
- 焦点管理沿用抽屉语义：打开时焦点进页面标题（tabIndex=-1），返回时还给触发
  按钮（App 在打开一刻捕获 `document.activeElement`，关闭后 `setTimeout(0)` 归还
  ——与 AppDrawer 注释记载的 Radix 时序同理，触发按钮可能随 active 态重渲染）。

### D-B19-2 页面编排

```text
← 返回
设置                                    ← h2，页标题
配置生成模型、联网搜索与本地运行状态。

┌──────────┬────────────────────────────────────┐
│ 模型服务  │  [模型服务]  已配置服务列表          │
│ 联网搜索  │             + 添加模型服务（折叠）    │
│ 本地运行  │  [联网搜索]  Tavily key             │
│ (锚点导航) │  [本地运行]  数据服务/桌面服务/版本   │
└──────────┴────────────────────────────────────┘
```

- 内容列 `max-w-[960px]` 居中；≥768px 左侧 168px 锚点导航（sticky），点击平滑滚动
  到分区；<768px 锚点导航隐藏（三个分区总高有限，直接纵向滚）。
- 三个分区各成一张卡（`rounded-2xl border bg-card`），沿用抽屉时代的
  图标 + 标题 + 说明头部（Sparkles/Search/Database），分区语义与文案不变。
- 锚点导航用 `scrollIntoView`（容器内滚动），不引入路由——App 至今无 router，
  设置页不是引入它的理由。

### D-B19-3 模型服务区编排修正（评审 B20 项提前）

- **已配置服务列表在前**，新增表单收进「添加模型服务」按钮（点击展开为带标题的
  表单卡，可收起）；**无服务时表单直接展开**（此时它就是首要任务）。
- ProviderRow 按钮重排：常规操作在左（API Key 录入/测试连接/设为默认），破坏性
  操作（删除密钥/删除服务）`ml-auto` 右移分组——原布局里红色「删除密钥」占
  按钮行首位。二次确认、焦点管理、Escape 取消等既有行为不动。

## 2. 不做什么

- 不引入前端路由（无 URL 直达设置页；需要时另议）；
- 不动 ProviderRegion 的数据流与校验逻辑（纯布局/排序调整）；
- 不做外观/阅读偏好等新设置项（未来批次按需加分区，本批只搬现有三区）。

## 3. 测试影响

- app.test.tsx：`openSettingsDrawer` 助手改为断言页面标题（原断言 `role=dialog`）；
  「关闭恢复焦点」用例改走「返回」按钮；其余经设置面交互的用例仅改打开方式。
- ProviderRegion.test.tsx：新增流程三用例先点「添加模型服务」展开表单（默认
  providers 非空 → 折叠）。
- 新增：设置页可达性用例（打开 → 三分区标题可见 → 返回恢复原视图与焦点）。

## 4. 验证基线

`pnpm check` 全绿；浏览器实测：桌面亮暗 × 设置页布局/锚点滚动/返回焦点，
375pt 单列布局 + 底部导航进出设置页；从项目内进设置返回后旅程阶段不丢。
