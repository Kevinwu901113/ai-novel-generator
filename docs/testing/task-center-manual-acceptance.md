# 任务活动中心 — 人工验收指南

## 前置条件

- 应用已启动，数据服务就绪
- 至少有一个已创建的项目

---

## 1. 打开项目查看任务活动区域

**操作：**

1. 在左栏点击一个项目打开
2. 查看右栏（状态面板）

**预期结果：**

- 右栏出现"任务活动"折叠区
- 包含统计摘要、刷新按钮、任务列表、任务详情区域

## 5. 查看 Token 与延迟统计

**操作：**

1. 执行至少一次成功的模型调用测试
2. 查看统计摘要区域

**预期结果：**

- 显示：模型调用数、成功数、失败数
- 显示：输入 Token、输出 Token、总 Token
- 显示：总延迟、平均延迟
- 数值使用千位分隔符
- 延迟 < 1 秒显示 ms，≥ 1 秒显示秒

## 9. 确认 UI 不显示敏感信息

**操作：**

1. 点击一个已完成的任务查看详情
2. 检查所有显示的内容

**预期结果：**

- 不显示 prompt（提示词原文）
- 不显示响应正文（完整模型输出）
- 不显示绝对路径（如 /Users/...）
- 不显示完整任务 ID 或项目 ID（只显示前 8 字符）
- 不显示 API Key 或 provider 配置细节
- 错误信息中的路径和堆栈已被清理
