# PlotPilot Sidecar Integration

## Decision

PlotPilot runs as a local Python sidecar. The Electron renderer never calls it directly.
The intended call path is:

```text
Renderer -> Preload -> Main -> Worker -> @ai-novel/plotpilot-adapter -> PlotPilot FastAPI
```

This preserves the existing sandbox, typed IPC boundary, project database ownership, and user-text protection model while allowing the application to use PlotPilot's long-form generation runtime.

## Ownership boundaries

### AI Novel Generator owns

- project index and project lifecycle
- Grill-me sessions and creation contracts
- editable manuscript revisions
- user-authored text protection
- approval records and patch acceptance
- application API keys and desktop security
- the mapping between local projects/chapters and PlotPilot novels/chapters

### PlotPilot owns

- narrative-engine runtime state
- generation pipeline checkpoints
- contextual retrieval and vector indexes
- knowledge graph and foreshadowing ledger
- quality analysis generated by the sidecar
- hosted multi-chapter generation state

The two applications must not share a writable SQLite database. Synchronization is performed through typed DTOs and content hashes. The local manuscript revision is the source of truth for user-confirmed text; PlotPilot only manages its own runtime and retrieval state.

## Implemented foundation

The `@ai-novel/plotpilot-adapter` package provides:

### HTTP adapter (`PlotPilotAdapter`)

- typed `/health` normalization
- safe `/internal/shutdown` invocation
- chapter-generation SSE consumption
- hosted multi-chapter SSE consumption
- stable error codes: `PLOTPILOT_ABORTED`, `PLOTPILOT_TIMEOUT`, `PLOTPILOT_UNAVAILABLE`, `PLOTPILOT_HTTP_ERROR`, `PLOTPILOT_RESPONSE_INVALID`, `PLOTPILOT_BUFFER_OVERFLOW`
- caller abort vs internal deadline distinction
- no response body leakage in HTTP errors

### SSE parser (`parseSseStream`)

- LF and CRLF separators, including split across chunks
- UTF-8 multi-byte characters split across chunks
- multiline `data:` fields
- `event`, `id`, `retry`, and comment fields
- `[DONE]` sentinel handling
- last frame without trailing separator
- per-event and total buffer size limits
- iterator `return()` cancels and releases the reader
- abort signal cleanup

### Sidecar lifecycle (`PlotPilotSidecarManager`)

States: `STOPPED`, `STARTING`, `READY_OWNED`, `READY_EXTERNAL`, `STOPPING`, `FAILED`.

- single-flight `start()`: concurrent callers share one promise, only one spawn
- owned vs external process distinction: `stop()` never kills an external service
- `spawn` with `shell: false`, executable and args separated
- `error`, `exit`, and `close` events settle state exactly once
- readiness timeout reclaims owned child with SIGKILL
- stop timeout escalates SIGTERM → SIGKILL deterministically
- injectable clock for deterministic testing
- config validation: checkout dir, entry file, python executable, port range, loopback-only binding

### Security constraints

- PlotPilot checkout path is user-provided; no git clone, pip install, or network download
- no shell command concatenation
- renderer never specifies executable or argv
- API keys never appear in argv, logs, errors, or persisted config
- errors do not leak Python paths, user directories, env, or stack traces
- base URL defaults to loopback HTTP; non-loopback binding is rejected

## Required environment

The sidecar manager receives the PlotPilot checkout path explicitly. No absolute local path is stored in source control.

Recommended local settings:

```text
PLOTPILOT_ROOT=/absolute/path/to/PlotPilot
PLOTPILOT_PYTHON=/absolute/path/to/python
PLOTPILOT_PORT=8005
```

The manager launches:

```text
python -m uvicorn interfaces.main:app --host 127.0.0.1 --port 8005
```

## Synchronization invariant

Before automatic generation continues to the next chapter:

```text
local manuscript revision hash == PlotPilot chapter content hash
```

A user edit changes the local hash and places the chapter in `LOCAL_AHEAD`. The application must push the approved revision back to PlotPilot and rebuild affected narrative projections before allowing hosted writing to continue.
