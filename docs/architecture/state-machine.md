# 状态机

## 项目状态

```
┌──────┐   ┌─────────┐   ┌──────────┐   ┌──────────┐
│ idea │ → │ grill-me│ → │ research │ → │ contract │
└──────┘   └─────────┘   └──────────┘   └──────────┘
                                              │
                                              ↓
┌───────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│ completed │ ← │ reviewing│ ← │ drafting │ ← │ planning │
└───────────┘   └──────────┘   └──────────┘   └──────────┘
```

### 状态说明

| 状态        | 说明         | 关键活动              |
| ----------- | ------------ | --------------------- |
| `idea`      | 模糊想法阶段 | 用户输入初始想法      |
| `grill-me`  | 需求澄清中   | AI 多轮对话，挖掘需求 |
| `research`  | 资料研究中   | 收集原作、人物资料    |
| `contract`  | 创作契约阶段 | 生成和确认创作契约    |
| `planning`  | 规划中       | 生成章节大纲          |
| `drafting`  | 正文创作中   | 生成样稿和正文        |
| `reviewing` | 审稿中       | 多轮审稿和修复        |
| `completed` | 已完成       | 最终确认              |

### 状态转换规则

- 可以前进到下一个状态
- 可以回退到前一个状态（需要用户确认）
- 不能跳过中间状态（除非用户明确要求）
- 任何状态都可以回到 `idea`（重新开始）

## 任务状态

```
┌─────────┐   ┌────────────┐   ┌───────────┐
│ pending │ → │ in-progress│ → │ completed │
└─────────┘   └────────────┘   └───────────┘
                    │
                    ↓
              ┌──────────┐   ┌─────────┐
              │ blocked  │ → │ failed  │
              └──────────┘   └─────────┘
```

### 状态说明

| 状态          | 说明                 |
| ------------- | -------------------- |
| `pending`     | 待处理，等待执行     |
| `in-progress` | 进行中               |
| `blocked`     | 被阻塞，等待依赖完成 |
| `completed`   | 已完成               |
| `failed`      | 失败，需要人工干预   |

## 决策范围

决策影响的范围层级：

| 范围      | 说明       | 示例                       |
| --------- | ---------- | -------------------------- |
| `project` | 项目级决策 | 修改项目标题、改变整体风格 |
| `chapter` | 章节级决策 | 调整章节顺序、修改章节主题 |
| `scene`   | 场景级决策 | 修改场景描写、调整对话     |
| `line`    | 行级决策   | 修改特定句子、调整用词     |

## 状态与版本

- 每次状态变更都生成版本快照
- 支持回滚到任意历史版本
- 版本记录包含：状态、变更内容、变更原因、时间戳

## ChangeSet 机制

跨模块更新使用 ChangeSet：

```typescript
interface ChangeSet {
  id: string; // 唯一标识
  scope: DecisionScope; // 决策范围
  targetId: string; // 目标对象 ID
  changes: ChangeEntry[]; // 变更列表
  createdAt: string; // 创建时间
  reason: string; // 变更原因
}
```

- 所有跨模块变更都通过 ChangeSet
- ChangeSet 是原子操作
- 支持撤销和重做
